# typeheat

A minimal typing test. The faster you type, the hotter the screen glows.

- Time and word modes, punctuation and numbers toggles
- Fast-erase backspace (one key deletes a word) or classic
- Results: WPM, raw, accuracy, consistency, speed chart, missed-key heatmap
- Three themes, `Tab` to restart

## Run locally

```
npm install
npm run dev
```

## Deploy

Push to `main`. The GitHub Actions workflow builds and publishes to GitHub Pages
(repo Settings → Pages → Source: GitHub Actions).
